# شاڕۆ پارتنەر | Sharo Partner Portal
**ناسێنەری پاکێج (Bundle ID):** `com.sharo.partner`  
**فرەیمۆڕک:** Flutter 3.24.5 / Dart 3.5.4  
**مۆڵەت (License):** MIT License

ئەپڵیکەیشنی فەرمی خاوەن چێشتخانە، مارکێت و فرۆشیارانی تۆڕی **شاڕۆ (Sharo)** بۆ بەڕێوەبردنی کڕین و فرۆشتنی بازرگانی بە شێوازێکی پیشەگەر.

---

## تایبەتمەندییە سەرەکییەکان
- **بەڕێوەبردنی تەواوی مێنیو (Full Menu CRUD):**
  - زیادکردنی خواردنی نوێ (ناوی خواردن، نرخ، بەش، و وێنە).
  - دەستکاریکردن و گۆڕینی نرخی خواردن بە شێوەی ڕاستەوخۆ.
  - سڕینەوەی خواردن لە مێنیو.
  - سوویچی بەردەستبوون یان نەمان (Available / Sold Out).
- **بەڕێوەبردنی داواکارییەکان لە کاتی ڕاستەقینەدا:**
  - وەرگرتنی داواکاری بە ئاگاداری و زەنگ.
  - دیاریکردنی کاتی ئامادەکردن لە چێشتخانە.
  - ئاگادارکردنەوەی دەستبەجێی کاپتنی گەیاندن کاتێک خواردنەکە ئامادە دەبێت.
- **داهات و ڕاپۆرتی ڕۆژانە:**
  - کۆی فرۆش، پشکی پاکی چێشتخانە (٨٥٪)، و پشکی خزمەتگوزاری.
- **دۆخی دووکان:** گۆڕینی کراوە یان داخراو بە یەک کرتە.
